Implement an integrated, end-to-end Payout Execution & Error Shield pipeline in Node.js/TypeScript that combines two core capabilities:
1. **Automated Supplier Settlement (Text-First Command Parser)**
2. **Smart Compliance & Error Shield (PayPal Doctor & Fallback Handler)**

# IMPLEMENTATION REQUIREMENTS

## MODULE 1: Automated Supplier Settlement (`src/services/settlementService.ts`)
- Build an AI-powered intent parser using OpenAI (sole runtime AI provider; model via `OPENAI_MODEL` env, default `gpt-4o`). Sole FX source: Frankfurter API (ECB reference rates). Payout currencies: USD, EUR, GBP, SGD only — never VND. It must accept natural language instructions (e.g., "Pay all due invoices to European suppliers in EUR this week").
- The agent must:
  1. Extract structured parameters: target region/country, currency (`EUR`), time window (`this week`), and action intent.
  2. Query the internal database/mock ledger for matching pending supplier invoices.
  3. Prepare a batched payload conforming strictly to the **PayPal Payouts REST API** (`POST /v1/payments/payouts`).
  4. Ensure a unique `PayPal-Request-Id` is generated for every batch to enforce idempotency.

## MODULE 2: Smart Compliance & Error Shield (`src/services/errorShieldService.ts`)
- When the batch payout request is sent to the PayPal Sandbox endpoint, intercept any non-200 responses or item-level failures (e.g., local currency restrictions in specific countries, compliance blocks, or token expirations).
- Integrate an error-handling wrapper inspired by **PayPal Doctor / Explain Error**:
  1. Analyze error codes returned by the PayPal API (e.g., restriction/compliance errors).
  2. Automatically trigger a fallback remediation strategy:
     - *Strategy A (Batch Splitting):* Separate restricted recipients into a secondary batch.
     - *Strategy B (Currency Intermediation):* Suggest or auto-switch the settlement currency to an accepted intermediary currency (like USD) if local currency conversion is restricted.
  3. Log the structured audit trail and provide clear, actionable diagnostics for the treasury admin dashboard.
